# Third-Party Design References

The mobile UI layer in this repository was independently adapted for the web using general interaction and layout patterns from the following open-source mobile projects. No project branding, logos, screenshots, or proprietary assets are included.

## CryptoTrader Flutter — Modern Cryptocurrency Exchange App UI
- Repository: Hamed233/CryptoTrader-Flutter---Modern-Cryptocurrency-Exchange-App-UI
- License: MIT
- Used as a reference for mobile trading-screen information hierarchy, compact price/stat presentation, horizontal timeframe controls, trading-oriented card spacing, and mobile navigation patterns.

## OpenAlgo Mobile Terminal
- Repository: marketcalls/openalgo-mobile
- License: AGPL-3.0
- Used for high-level product/UX reference only. No OpenAlgo source code was copied into this repository.

The RWA market-data engine, Binance integrations, TradingView embedding, market discovery system, desktop UI, and responsive web implementation remain native to this repository.
