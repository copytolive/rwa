Full Tick Backtest · Chat + Public GitHub Requests

For the multi-asset universe above, GitHub downloads the required Dukascopy historical bid/ask ticks, runs the simulation, and saves a public JSON result with dataset SHA-256 and evaluation ID.

Example chat: Backtest XAUUSD 2020-01-01 to 2025-01-01, SMA 50/1000, RR 1:2, both directions.

Public GitHub requests are capped at 7 calendar days per job to protect shared compute. Longer research campaigns can be issued through the owner/chat workflow. Historical simulation only; no broker execution.
