# Launch V6 Status Interpretation

- `engineering_ready=true` means the repository safety/runtime contracts pass; it is not permission to trade mainnet.
- `multichain.ready=true` means the five real receipt classes plus LI.FI and Hyperliquid provider gates pass.
- `beta_passed=true` means the canonical 3/20/100 unique-wallet thresholds pass.
- `mainnet_ready=true` means the global gate passes and final mainnet control is enabled.
- `launch_go=true` in the V6 auditor additionally requires the explicit LI.FI production revenue and Hyperliquid builder workstreams plus the production services/evidence gates.

Any mismatch or missing proof must resolve to `NO-GO`.
