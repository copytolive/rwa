# Canonical integration

This repository is the complete UI source for the RWA product.

- UI source of truth: `copytolive/realworldasset`
- System/runtime source of truth: `copytolive/rwa`
- Canonical public production: `https://copytolive.github.io/rwa/`
- `copytolive/rwa` vendors this complete UI under `ui/realworldasset/` and builds production from it.
- Pages for this repository redirects to the canonical `/rwa/` production URL.
