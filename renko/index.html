Fixed historical source

Production is intentionally locked to Binance 1-second closed klines and Close values. There is no user-selectable chart timeframe.

Realtime projection

Current 1-second bricks are provisional projections and become confirmed only when that 1-second source kline closes.

Traditional

Fixed absolute box. Continuation requires 1× box; reversal requires 2× box.

Percentage (LTP)

Latest closed price × user percent, rounded to the nearest exchange minimum tick and applied consistently across the rebuild.

ATR

Wilder ATR is calculated from ordinary 1-second OHLC source candles while Renko formation uses their Close values. A positive raw Wilder ATR is used directly as box size without minimum-tick rounding; large look-backs are prepared in a Web Worker so the visible chart remains responsive.

Wicks

Close source uses discarded Close extrema. Up bricks carry low wicks; down bricks carry high wicks.

Deep history

Deep ATR history is lazy-started only after explicit ATR interaction. Once activated, history and Wilder state are maintained in a background Web Worker. The displayed coverage dates are locked to unique non-overlapping 1-second worker timestamps and must expand backward with larger ATR look-backs.

Stable chart rendering

The 1-second source continues to close every second, but redundant open-kline and identical chart writes are suppressed. App-authored latest/zoom range changes are not treated as user left-edge pans, preventing accidental repeated old-history rebuilds.

Exact-output limit

TradingView does not publicly specify every proprietary historical traversal/anchoring detail. This page matches the published Renko rules within the fixed 1s Close source profile rather than claiming proprietary byte-for-byte identity.
