Private full history

For pairs supported by the private Seablueprint/CopyToLive Renko engine, the page requests all Renko pages with the same fixed box and joins them from the earliest available brick through live.

Traditional box

Continuation requires one fixed box and reversal requires two boxes. This is the same Traditional 2-brick construction used by the private Renko route.

Historical source disclosure

The private historical engine is not falsely labelled tick-only: it currently reports real H1 market observations plus recorded Hyperliquid trades. The exact backend source and data-quality label are shown above the chart.

Live source

Supported private pairs continue from the private Hyperliquid live stream. If private history is unavailable for a selected market, the chart falls back to Binance individual @trade ticks.

500-market universe

The first 500 eligible Binance crypto markets are shown by 24-hour USD-equivalent liquidity and the full eligible universe remains searchable.

Synthetic chart

Renko brick prices are synthetic. Any trading fill must continue to use the real venue price through the RWA execution path, never a synthetic brick close.
