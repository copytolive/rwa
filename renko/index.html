Historical source

The selected chart interval supplies Close or OHLC values. Confirmed history changes only after that source interval closes.

Realtime projection

Current-interval bricks are provisional projections. They can change or disappear and are rebuilt from the current source bar until it closes.

Traditional

Fixed absolute box. Continuation requires 1× box; reversal requires 2× box.

Percentage (LTP)

Latest closed price × user percent, rounded to the nearest exchange minimum tick and applied consistently across the rebuild.

ATR

Wilder ATR is calculated from ordinary source-interval OHLC candles and used as the Renko box size. ATR Length is a real look-back period; large values load enough available source history instead of being silently clamped.

Wicks

Close source uses discarded close extrema. OHLC source uses actual High/Low excursions. Up bricks carry low wicks; down bricks carry high wicks.

Deep history

Older Binance source bars load progressively. TradingView itself may substitute higher intervals when its own lower-timeframe history ends; Binance history depth differs.

Exact-output limit

TradingView does not publicly specify every proprietary historical OHLC traversal/anchoring detail. This page matches the published contract and exposes the remaining undocumented boundary instead of claiming false 100% byte-for-byte output parity.
