RENKO V10 methodology, accuracy & operating rules
Auto Adaptive — recommended

ATR(14) estimates volatility, multiplied by the Auto Factor (default 0.50), then the absolute box is locked for 30 minutes. If a position signal is active, automatic recalculation is postponed until the engine returns flat.

Traditional

Fixed absolute box. Continuation requires one box. Direction reversal requires two boxes. This is the most stable and easiest mode to audit.

ATR

Brick size follows ATR calculated from completed 1-minute OHLC. Historical bricks use the ATR available at each source bar. Live bricks use the latest completed ATR snapshot until the next completed minute refresh.

Percentage

Brick size is a percentage of the current confirmed Renko level. This normalizes the chart across assets but can change with price and should be treated as more adaptive than Traditional.

Projected vs confirmed

The transparent projected candle follows the real market price but is labelled NO SIGNAL. Entry/exit logic only reacts after a full Renko threshold has been crossed and the brick is confirmed.

Entry default

The safer default is reversal confirmation plus one continuation brick. Set “First reversal” only for a more aggressive, earlier signal with higher false-reversal risk.

Exit stack

Layer 1: raw-market hard stop. Layer 2: one-box Renko trailing reference. Layer 3: confirmed opposite Renko reversal. Raw market stop can exit before a synthetic reversal brick completes.

Price integrity

The blue REAL line and execution guidance use Binance venue price. Renko close levels are synthetic structure levels and are not treated as guaranteed order-fill prices.

Historical accuracy boundary

Live formation uses individual Binance @trade ticks. Deep chart history uses completed 1-minute OHLC for fast loading, so historical brick sequencing can differ from a complete tick-by-tick reconstruction.
